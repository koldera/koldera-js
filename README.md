# koldera-js

JavaScript and TypeScript SDK for [koldera-core](https://github.com/koldera/koldera-core): PDF/UA checks and fixes,
HTML and structured documents to tagged PDF, web scans. Node, browsers and React.

| Package | Purpose |
|---|---|
| `@koldera/sdk` | Server client (`@koldera/sdk/node`), browser client (`@koldera/sdk/browser`), shared types |
| `@koldera/react` | `KolderaProvider` and hooks over the browser client |

Targets koldera-core API 0.1 (`contracts/CORE_VERSION`). Licence: Apache-2.0.

Documentation is in progress.
